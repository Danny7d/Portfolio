# Daniel Tadesse — Portfolio

**Live:** [https://danny.tably.site](https://danny.tably.site)

Personal portfolio of Daniel Tadesse — engineering student at AASTU, self-taught full-stack developer, and solo founder building products in public from Addis Ababa, Ethiopia.

## What’s inside

- **Hero** — clear positioning as a solo founder shipping real software
- **Featured Projects** — deeper write-ups of the products I have built and shipped
- **Skills** — practical tech stack I use daily
- **About** — background, focus, and how I work
- **Contact** — easy ways to reach me

## Tech stack

- **Framework:** Next.js (App Router) + React + TypeScript
- **Styling:** Tailwind CSS, custom glassmorphism + animations
- **Deployment:** Vercel

## Getting started

```bash
git clone https://github.com/Danny7d/Portfolio.git
cd Portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
